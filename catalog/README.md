# 拍间离线曲库

本目录包含 1000 个不同 Mutopia 官方曲谱条目的原始主 MIDI 文件，共 9668887 字节。曲目若是作品集中的独立曲目或乐章，其收录范围以原标题及作品编号为准。没有截取源文件，也没有用同一曲目的分声部练习文件补数。

每项的来源链接、原始 MIDI 下载地址、版本、贡献者署名、许可证与许可证链接、SHA-256、总时长及验证结果保存在 index.json。index.js 是相同数据的浏览器版本。MIDI 字节未修改；界面数字谱按当前转换器的节奏网格和所选琴型生成，逐项保留校对说明。

优先采用 Public Domain；不足的部分采用允许再分发的 Creative Commons 作品，完整保留署名及许可链接。请在再分发或改编时保留对应条目的来源与授权信息。原始官方批量元数据快照位于 sources/mutopia-musiccache.dat。

重建：使用支持 fetch 的 Node.js 运行 node tools/build-catalog.cjs。最多 6 个并发请求，缓存默认保存在 /tmp/paijian-mutopia-catalog；可通过 PAIJIAN_CATALOG_CACHE 指定缓存目录。每个候选须通过 MIDI 完整性、完整多声部模型及播放器验证，源 ID、文件字节、移调归一化音乐事件序列和作曲者/标题/作品编号均经过重复检查。失败项记录在 build-report.json。

另对规范化作曲者与作品编号的候选分组进行了语义复核，剔除了 14 个已确认的同曲不同制谱或编配版本，并排除单独主题、变奏片段及历史未完成条目。semantic-review.json 保留筛选前候选快照与最终排除决策；它不是当前条目清单，也不表示穷尽所有音乐学同一性判断。
