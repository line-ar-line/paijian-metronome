# 小黑陪练 · 手绘差分素材

这组素材使用 SVG 路径直接绘制，没有调用位图生成服务，也没有复制、下载官网图片。它们是《罗小黑战记》同人界面插画，**不是官方素材，也不表示获得官方授权**。角色及原作品相关权利归原权利人；请勿把本目录描述成官方开源素材包，或用项目代码许可证替代角色权利说明。

## 文件与状态

| 文件 | 改动区域 | 用途 |
| --- | --- | --- |
| `companion-idle.svg` | 基准图，睁眼、双爪抱木质卡林巴 | 待机 |
| `companion-blink-half.svg` | 只更换眼睛 | 眨眼过渡 |
| `companion-blink.svg` | 只更换眼睛 | 闭眼关键帧 |
| `companion-ready.svg` | 右爪略移、增加小音符 | 开始练习/播放 |
| `companion-wave.svg` | 笑眼、嘴角、右爪举起和挥手线 | 打卡/完成反馈 |
| `companion-rest.svg` | 闭眼、嘴角微笑 | 暂停或休息 |
| `heixiu.svg` | 独立的小嘿咻同人图标 | 小拍点、空状态 |
| `forest-canopy.svg` | 自行设计的左右枝叶，无角色图案 | 页头、卡片背景 |

## 锚点和加载

- 六个完整角色 SVG 都采用 `viewBox="0 0 320 320"`，根背景透明。
- 身体、头部轮廓、尾巴、脚底、琴体完全共享，脚底在 y = 304；切帧时不要分别裁切为不同尺寸。
- 各部件以 `data-part` 标记，方便将来把眼睛、手爪提取为独立图层。
- 推荐先以 `<img width="320" height="320">` 固定宽高比，CSS 设置实际宽度，`object-fit: contain`，切换 `src` 实现差分。
- 建议显示尺寸：首页 180–220 px，卡片 96–128 px，谱页角落约 72 px；小尺寸时装饰图应 `alt=""`，避免重复播报角色状态。
- 拍点图标 `heixiu.svg` 的画布为 64 × 64，可显示为 20–32 px。
- 森林枝叶画布 1000 × 240，中央留白，可作轻量背景图，不承担页面文字可读性。

## 推荐时序

- 眨眼：idle → half 70 ms → closed 110 ms → half 70 ms → idle；两次眨眼之间留出若干秒。
- 庆祝：ready 130 ms → wave 420 ms → ready 130 ms → wave 460 ms → rest 350 ms → idle。
- 一次庆祝约 1.5 秒，完成后回到当前实际播放状态。
- 切换前预加载六帧；页面隐藏时停止计时器；遵循 `prefers-reduced-motion`，减少动态效果。
- 节拍反馈应跟随音频引擎的实际拍点；这组关键帧自身不提供计时，也不应该驱动音频。

用 `python3 theme/assets/build-frames.py` 可以从共享基准重新生成六帧。此脚本只写六个 companion SVG；不会覆盖森林图、拍点图或网站集成代码。

在 `theme/frames-preview.html` 查看六帧排版和手动动画预览。
